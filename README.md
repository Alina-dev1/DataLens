# DataLens

**DataLens** is a modern, responsive data analytics dashboard designed to turn complex data into clear and understandable insights.

The project combines a polished analytics interface with interactive dashboard components and a CSV-upload workflow.

## ✨ Features

* Modern analytics dashboard
* Responsive landing page
* Analytics overview section
* Dashboard statistics
* Interactive time-period filter:

  * Last 7 days
  * Last 30 days
  * Last 3 months
* Dynamic dataset statistics
* Dynamic record statistics
* Dynamic insight percentage
* SVG-based analytics graph
* Interactive report button
* CSV upload workflow
* File selection interface
* Data analysis workflow modal
* Email signup validation
* Smooth scrolling navigation
* Feature and CTA navigation buttons
* Modern UI sections for:

  * Features
  * How It Works
  * Statistics
  * Contact

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* SVG
* DOM Manipulation

## 🚀 Getting Started

```bash
git clone https://github.com/Alina-dev1/DataLens.git
```

### 2. Open the project

Open the project folder in your code editor.

## 📊 Dashboard

The dashboard displays key analytics such as:

* Total datasets
* Total records
* Insights found
* Active projects

The analytics section changes based on the selected time period.

The JavaScript dashboard data currently includes separate values for **Last 7 Days**, **Last 30 Days**, and **Last 3 Months**, with the graph updating accordingly.

## 📁 CSV Upload Workflow

DataLens includes an interactive workflow for uploading CSV data.

The workflow guides the user through:

1. Uploading a CSV file
2. Preparing the data for analysis
3. Analyzing the uploaded data
4. Exploring the resulting insights

The interface uses a modal workflow to guide the user through these steps.
